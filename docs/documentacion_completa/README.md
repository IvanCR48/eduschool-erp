## 🎨 Estilo de Documentación

Todos los documentos siguen el mismo estilo y estructura:

- **Header con gradiente** del color principal del sistema
- **Secciones claras** con iconos descriptivos
- **Código resaltado** con bloques de código

- **Navegación** con botón para volver al índice

## 📝 Cómo Usar

1. Accede a la documentación desde el hub principal: `documentacion.php`
2. Navega por categorías
3. Haz clic en el documento que necesites
4. Usa el botón "Volver" para regresar al índice
